# Faculty Consultation Log

The Faculty Consultation Log is a centralized digital system designed to replace manual logbooks and spreadsheet tracking. It enables students to book appointments and allows faculty members to efficiently document, track, and review academic mentoring, project guidance, and office-hour consultations.

# 🌟 Key Features

• Appointment Scheduling: Streamlined booking system for students to reserve open time slots with professors.
• Digital Consultation Logs: Digital forms for faculty to record meeting summaries, actionable next steps, and student progress.
• Dashboard Analytics: Visual insights showing consultation trends, frequent topics, and student engagement metrics.
• Role-Based Access: Secure, separate interfaces for Students, Faculty, and Department Administrators.
• Automated Notifications: Email reminders for upcoming meetings and follow-up actions.
